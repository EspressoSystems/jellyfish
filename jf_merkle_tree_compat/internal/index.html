Internal data structures and algorithms for Merkle tree implementations.

This module provides the core building blocks for various Merkle tree schemes, including node representations, proof structures, and tree construction algorithms.

§Key Components

  • MerkleNode: The fundamental node type representing leaves, branches, and forgotten subtrees in a Merkle tree
  • MerkleTreeCommitment: A succinct commitment to a Merkle tree consisting of a root hash, height, and leaf count
  • MerkleProof: Proof structures for membership and non-membership verification
  • MerkleTreeIter: Iterator types for traversing tree elements

§Tree Construction

This module provides internal functions for building Merkle trees:

  • build_tree_internal: Constructs a full Merkle tree from elements
  • build_light_weight_tree_internal: Constructs a lightweight tree with most nodes forgotten except the frontier

§Internal Operations

The module implements core tree operations including lookup, insertion, update, and forget/remember functionality through methods on MerkleNode.
